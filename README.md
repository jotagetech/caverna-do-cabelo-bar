# Caverna do Cabelo

Landing page do bar esportivo Caverna do Cabelo, em Lucélia-SP.

Site estático (HTML, CSS e JavaScript puros, sem framework nem build step).

## Estrutura

```
index.html       # marcação e conteúdo da página
styles.css        # estilos
interactions.js   # a animação de futebol na seção "A experiência"
assets/           # imagens, logotipo e a animação Lottie do futebol
```

## Rodando localmente

Qualquer servidor estático simples funciona, por exemplo:

```
python3 -m http.server
```

Abrir `http://localhost:8000` no navegador.
